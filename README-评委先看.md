# 有据 · AI 侦探社 v4.2.1

把一个生活疑问，查成有来源、有过程、能复核的调查档案。

## 先看作品与三次实测

1. 解压整个压缩包。先打开 `提交材料/演示索引.html`：不用安装软件或填写密钥，即可查看三次实际查询的结果截图、原始档案、请求编号和来源链接。
2. 运行交互作品：Windows 双击根目录的 `一键启动.bat`，会自动启动服务并打开网页。也可使用 `打开有据.vbs` 或 `打开有据.cmd`。需要 Node.js 20.3 或更新版本，不需要安装第三方依赖。也可在解压目录执行 `node server.mjs`，再打开启动时显示的本机网址。
3. 首页点击「看一遍追查过程」体验流程；「登录 / 注册 → 案例用户」可免密码体验四种社区身份；侧栏「热点追踪」可直接读取实时图文资讯。
4. 进行新的真实调查时，点右上角「连接元宝搜索」，填写评审者自己的服务 API Key。截图识别与 AI 归纳另外需要兼容模型接口。不配置 AI 也能搜索、人工判断和导出。

## 建议的 90 秒体验

- 0—20 秒：首页看三步交互演示，理解从说法到证据档案的路径。
- 20—50 秒：在演示索引查看「故宫周一闭馆」案例，打开官方来源，核对三轮请求记录；再看塑料编号和电影线索案例。
- 50—70 秒：打开热点追踪，查看源站发布时间、获取时间、图文与视频入口。
- 70—90 秒：用案例身份进入查证广场，体验身份切换与带来源的讨论流程。

## 这份包包含什么

- `public/`、`lib/`、`server.mjs`：完整作品代码。
- 启动器与使用说明：本机启动和搜索连接方式。
- `提交材料/演示索引.html`：三次真实查询的离线可读演示索引。
- `提交材料/真实查询/`：故宫 20 条来源、塑料编号 19 条来源、电影线索 10 条来源的实际查询档案；对应截图、Markdown 报告和来源链接检查记录。
- `tests/`、`验证记录.md`、`提交前验收与锐评.md`：测试和评审边界。模拟测试截图未作为三次实测材料打包。

## 使用边界

这是本机运行的作品；`127.0.0.1` 是本机地址。评审者需要解压并启动，不能用作者电脑的本机地址远程访问。官方赛道允许未上线网页上传 ZIP。

压缩包不包含作者的 API Key、账户数据库、密码或浏览器会话。案例身份在首次点击时建立，现有实测档案供复核，不冒充评审者新发起的查询。

热点快讯来自 IT之家和 NASA 的公开订阅，并非全网热榜；快讯每 2 分钟检查，关注话题可自愿开启每 5 分钟搜索。自动检查要求相应页面保持打开且可见。每次关键词检查使用 1 次元宝搜索。

来源摘要、AI 归纳及社区身份都不等于事实认证；请打开原文核对日期和条件。案例用户是演示身份，不具备管理员权限或真实专业资质认证。

更详细的操作见 `使用说明.md`，比赛说明见 `参赛演示与提交.md`。
